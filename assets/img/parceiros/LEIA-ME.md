# Logos dos passes parceiros

Coloque os arquivos **nesta pasta** com estes nomes:

| Arquivo | Parceiro |
| --- | --- |
| `wellhub` | Wellhub (antigo Gympass) |
| `classpass` | ClassPass |
| `namu` | Namu Pass |

A extensão pode ser `.svg`, `.png` ou `.webp` — só mantenha o nome antes do ponto.

## Formato, em ordem de preferência

1. **SVG** — é o ideal. Vetor: fica nítido em qualquer tela, pesa quase nada
   e não borra em tela de celular.
2. **PNG com fundo transparente** — serve bem. Peça a maior versão que
   tiverem (a partir de ~400px de largura).
3. **JPG** — evite. Não tem transparência, então o logo vem dentro de um
   retângulo branco que aparece por cima do card.

Não vale print da tela do app: sai serrilhado e com fundo.

## Onde conseguir

Os três têm kit de marca para estabelecimentos parceiros:

- **Wellhub** — no painel do parceiro, seção de materiais/marketing. O
  gerente de conta também envia se você pedir.
- **ClassPass** — página de imprensa/brand assets, ou pelo suporte a parceiros.
- **Namu** — pelo contato comercial que fez o cadastro do estúdio.

No e-mail, peça exatamente: *"kit de marca / logo em SVG ou PNG com fundo
transparente para uso no site do estúdio parceiro"*.

## O que eu faço com eles

Os três logos têm formatos bem diferentes (uns são só símbolo, outros são
nome escrito), então não dá para simplesmente jogar todos no mesmo quadrado.
Vou normalizar por altura óptica dentro de um card branco, com espaçamento
respeitando a área de proteção que os manuais de marca costumam exigir, e
mantendo cada logo sem alteração de cor ou proporção.

Se só um ou dois chegarem, tudo bem: os que faltarem continuam como estão
até você conseguir o resto.
